## Description

A workshop for people who know Rails and want to see what changes when the Rails 8 monolith runs on a cloud platform. In this order:

1. The app in this repository is a blueprint for Rails 8 in the cloud: one-line JSON logs, Solid Queue / Cache / Cable in three containers, private Active Storage with keyless signed URLs, PostgreSQL through an Auth Proxy sidecar, secrets mounted at runtime, and AI as a background job with no API key.
2. The codelab takes you from a local stack to that deployment in nine steps.
3. You practise working with a coding harness. Any harness: the repository does not require a specific one.

## Fast start

Clone the repository first:

```bash
git clone https://github.com/palladius/rails8-app-on-gcp.git
cd rails8-app-on-gcp
```

### Claude Code / Codex

Start your harness in the repository root (`claude` or `codex`). It picks up `AGENTS.md` on its own: `CLAUDE.md` is a symlink to it, and the skills are linked under `.claude/skills` and `.agents/skills`. Then paste:

```text
I am attending the Rails 8 on Google Cloud workshop at Helvetic Ruby.
Read AGENTS.md and workshop/landing-page/README.md, then guide me through
workshop/CODELAB.md one step at a time, starting with Step 0.
Run `just workshop-test` first and help me fix what fails.
Explain what a command does before you run it, and ask me before any command
that creates or changes Google Cloud resources.
```

### Antigravity

No harness yet? [Download Antigravity](https://antigravity.google/download) and sign in with a personal Gmail account. Open the cloned `rails8-app-on-gcp` folder as a project, then paste the same prompt:

```text
I am attending the Rails 8 on Google Cloud workshop at Helvetic Ruby.
Read AGENTS.md and workshop/landing-page/README.md, then guide me through
workshop/CODELAB.md one step at a time, starting with Step 0.
Run `just workshop-test` first and help me fix what fails.
Explain what a command does before you run it, and ask me before any command
that creates or changes Google Cloud resources.
```

### No harness at all

Every step can be done from the codelab and the `just` recipes alone. Run `just` to list them.

## Guardrails

- [`docs/CONSTITUTION.md`](../../../docs/CONSTITUTION.md): the rules of the repository, for people and for agents.
- `just workshop-test`: pre-flight diagnostics for your machine.
- `just workshop-eval N`: automated checks for Step N, mostly files and local tests. They do not verify the state of your deployed service.
